    Methodology
    UMSI Core = fixed T/B/V/D weights · UMSI Live = 0.20T + 0.20C + 0.20B + 0.15V + 0.10P + 0.10D + 0.05A
    Historical charts and forward-return studies use the fixed-composition UMSI Core. UMSI Live adds AAII and put/call without changing the historical benchmark. Scores use trailing historical percentiles. Fear-oriented raw variables are inverted so 100 is risk-on. Market breadth uses an RSP-versus-SPY relative-performance proxy in this free-data version.

    Stress = term structure + credit + VIX + drawdown pressure. Fragility = low-volatility complacency + curve complacency + narrow breadth + AAII optimism + low put/call + concentration proxy + price stretch. Fragility is a vulnerability measure, not a forecast.
